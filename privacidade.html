DADOS E AUTORIZAÇÃO

Política de Privacidade

Atualizada em 3 de novembro de 2026.

Esta política descreve o uso de dados pelo Boletim Matinal, aplicativo pessoal administrado por Itamar Vieira e executado em seu computador. O projeto utiliza os serviços de API do YouTube para operar o canal autorizado pelo titular.

Dados acessados e finalidade

A autorização Google utiliza o escopo youtube.force-ssl. O aplicativo consulta o nome e o identificador do canal autorizado, os identificadores e metadados dos vídeos e playlists utilizados e o estado de processamento e a visibilidade dos envios. Esses dados permitem confirmar o canal correto, enviar os boletins, organizar a playlist e retomar operações interrompidas sem duplicar uploads.

O aplicativo pode atualizar a visibilidade e a posição dos vídeos na playlist. A exclusão de um vídeo requer autorização expressa do titular. A permissão concedida pelo Google é mais ampla do que cada operação individual e pode ser revogada pelo titular a qualquer momento.

Também são armazenadas as preferências informadas no aplicativo, incluindo estado, cidades da previsão, coordenadas, fuso horário e opções de geração. Essas informações são utilizadas para preparar os boletins.

Armazenamento e proteção

Os tokens OAuth, os dados do cliente OAuth e as sessões retomáveis de upload são armazenados localmente com proteção do Windows DPAPI, vinculada à conta Windows que os salvou. A senha da conta Google não é solicitada nem armazenada pelo aplicativo.

Configurações, registros operacionais, roteiros, áudios, vídeos e dados das edições ficam no computador do responsável. A proteção das credenciais não significa que todos esses arquivos de conteúdo sejam criptografados. Os dados permanecem até sua exclusão pelo responsável; cópias de segurança feitas por ele devem ser tratadas separadamente.

Transmissão e serviços externos

O Google e o YouTube recebem os pedidos de autenticação, as consultas necessárias e os arquivos e metadados dos vídeos enviados. A disponibilidade de um vídeo depende das configurações e das regras do YouTube. Um vídeo não listado pode ser acessado por quem tiver seu link.

A API OpenAI recebe o texto do roteiro e as instruções de voz para produzir a narração. As credenciais Google não fazem parte desse envio. Os serviços de meteorologia recebem as coordenadas dos municípios consultados para fornecer a previsão. Essas transmissões servem às funções solicitadas pelo titular.

O aplicativo não vende os dados Google, não os utiliza para publicidade e não os utiliza para treinar modelos de inteligência artificial. Os dados são usados para executar as funções descritas nesta política.

Revogação e exclusão

O titular pode revogar o acesso em Conexões da Conta Google. Após a revogação, o aplicativo não poderá continuar acessando o YouTube com a autorização revogada.

Revogar o acesso não exclui automaticamente arquivos locais nem vídeos já enviados. O responsável pode excluir as credenciais e os dados locais da instalação, inclusive suas cópias de segurança, e gerenciar ou excluir vídeos diretamente no YouTube Studio. Para solicitar a exclusão de dados mantidos pelo responsável, utilize o e-mail de suporte apresentado na tela de consentimento do Google.

Este site e seus visitantes

Estas páginas informativas não incluem formulários, publicidade ou ferramentas próprias de análise de audiência. Se forem hospedadas no GitHub Pages, o provedor registra endereços IP para fins de segurança, conforme a Declaração de Privacidade do GitHub.

Políticas e contato

Aplicam-se também a Política de Privacidade do Google e as regras dos provedores utilizados. O uso de informações recebidas das APIs Google observará a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado aplicáveis.
